ANIMAH starter website

1. Open index.html in a browser to preview the design.
2. To publish free, use a static hosting provider such as Cloudflare Pages or GitHub Pages.
3. This is a front-end prototype only. It does not yet have real accounts, video storage, uploads, likes, or comments.
4. Before inviting the public, add authentication, secure media storage, moderation, reporting/blocking, privacy rules, and age-appropriate safety controls.
